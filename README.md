# 인터넷전문은행 중·저신용자 대출 규제 실효성 분석

코디세이 미션 — 시계열 데이터 분석 및 인사이트 리포트

## 문제의식
인터넷전문은행 3사(카카오뱅크·케이뱅크·토스뱅크)는 정부의 '중저신용자 대출 비중 30%' 규제 비율은 형식적으로 맞추고 있지만, 실질적인 위험 인수(고위험 차주 포용)나 금리단층 해소에는 소극적이었는지를 시계열 데이터로 검증한다.

## 폴더 구조
```
internet-bank-credit-inclusion/
├── data/                # 원본 데이터 (엑셀 데이터북에서 추출한 시트)
├── images/              # 시각화 결과물 (png)
├── fonts/               # 대시보드용 한글 폰트 (나눔고딕)
├── analysis.ipynb       # 분석 코드
├── dashboard.py         # 보너스 Streamlit 대시보드
├── REPORT.md            # 최종 분석 리포트
└── requirements.txt     # 의존성 목록
```

## 데이터 출처
- 학술제 1차 출처 엑셀 데이터북 (은행연합회·금융위 공시 원문 기반, v4)
- 주요 시트: `월별_평균신용점수`(취급월 기준 2023-07~2026-06, 108행), `월별_고금리비중`(취급월 기준 2022-12~2026-06, 127행, 토스뱅크 2개월 결측→보간 처리)
- 라이선스/이용 주의: 본 데이터는 은행연합회·금융위원회가 공시한 공개 통계를 학술제 조사 과정에서 정리한 것으로, 상업적 재배포 목적이 아닌 교육·연구 목적(코디세이 미션 제출용)으로만 사용함. 원본 공시 자료의 저작권은 각 공시 기관에 있음.

## 실행 방법
```bash
pip install -r requirements.txt
jupyter notebook analysis.ipynb
```
노트북 셀은 위에서부터 순서대로 실행한다.

## 분석 질문
1. (관찰) 3개 인터넷전문은행의 월별 평균신용점수는 하락·유지·상승 중 어떤 추세를 보이는가?
2. (관찰) 3개 인터넷전문은행의 8% 이상 고금리 대출 취급비중은 어떻게 변화했는가?
3. (해석) 평균신용점수 변화와 고금리 대출 취급비중 변화 사이에는 어떤 괴리가 나타나는가?
4. (해석) 서민금융 제외 평균금리-평균금리 스프레드는 은행별·시점별로 어떻게 다른가?
