## 1. 문제의식

인터넷전문은행 3사(카카오뱅크·케이뱅크·토스뱅크)의 중·저신용자 대출 관련 지표가 시간에 따라 어떻게 변화했는지를 분석한다.

정부의 중·저신용자 대출 확대 정책이라는 제도적 배경을 바탕으로, 월별 평균신용점수, 8% 이상 고금리 대출 취급비중, 금리 스프레드의 변화를 비교한다.

특히 고금리 대출 취급비중의 감소가 실제 차주 구성의 변화와 함께 나타났는지, 은행별 차이가 존재하는지를 시계열 데이터로 확인한다.

> **주의**: 본 분석에 사용한 집계자료만으로 규제와 대출 행태 사이의 인과관계를 직접 증명할 수는 없다. 따라서 데이터에서 확인되는 사실과 그에 대한 해석·가설을 구분하여 제시한다.

## 3. 데이터 출처

- 학술제 1차 출처 엑셀 데이터북 **데이터북_v4**
- 은행연합회·금융위원회 공시 원문 기반 자료

### 사용 데이터

분석 범위를 명확하게 하기 위해 데이터북의 다음 2개 시트만 사용한다.

| 시트 | 분석 기간 | 데이터 구성 |
|---|---|---|
| `월별_평균신용점수` | 2023-07 ~ 2026-06 | 36개월 × 3개 은행 = 108행 |
| `월별_고금리비중` | 2022-12 ~ 2026-06 | 43개월 × 3개 은행 중 2개 행 결측 = 127행 |

대상 은행: **카카오뱅크 · 케이뱅크 · 토스뱅크**

### 결측 데이터

`월별_고금리비중`에서 토스뱅크의 **2023-11, 2024-11** 두 개월은 원자료에서 해당 행이 확인되지 않는다.

분석에서는 두 시점을 앞뒤 관측값을 이용한 **선형보간**으로 처리했다.

### 라이선스 및 이용 주의

본 데이터는 은행연합회·금융위원회가 공시한 공개 통계를 학술제 조사 과정에서 정리한 자료이며, 본 프로젝트에서는 교육·연구 및 코디세이 미션 제출 목적으로 사용한다. 원본 공시자료의 저작권 및 이용 조건은 각 공시 기관의 정책을 따른다.

## 4. 분석 질문

기존 질문을 데이터가 실제로 보여줄 수 있는 범위에 맞게 구체화했다.

1. **평균신용점수 추세**: 3개 인터넷전문은행의 월별 평균신용점수는 하락·유지·상승 중 어떤 추세를 보이는가?
2. **고금리 대출 취급비중 추세**: 3개 인터넷전문은행의 8% 이상 고금리 대출 취급비중은 시간에 따라 어떻게 변화하는가?
3. **차주 구성과 가격 변화의 괴리**: 평균신용점수 변화와 고금리 대출 취급비중 변화 사이에는 어떤 괴리가 나타나는가?
4. **은행별 금리 스프레드 차이**: 서민금융 제외 평균금리 - 평균금리 스프레드는 은행별·시점별로 어떻게 다른가?

## 5. 분석 방법

### 5.1 데이터 전처리

- 취급월을 datetime 형식으로 변환
- 은행별 월별 데이터 정렬
- 은행별 월별 관측 여부 확인
- 토스뱅크 결측 2개월 선형보간
- 월간 변화량을 이용한 이상치 후보 탐색
- 통계적 이상치 후보도 실제 관측값이면 임의로 삭제하지 않음

### 5.2 시계열 분석

| 기법 | 설명 |
|---|---|
| ① 3개월 이동평균 | 월별 단기 변동을 완화하여 전체적인 추세를 확인한다. |
| ② 전월 대비 변화율 | 평균신용점수와 고금리비중의 변화 속도를 비교한다. 고금리비중이 0%인 경우 분모가 0이 되어 계산할 수 없으므로 `inf/-inf`를 NaN으로 처리한다. |
| ③ 전월 대비 %p 변화 | 고금리비중은 낮은 값에서 상대 변화율이 크게 나타날 수 있으므로 실제 비중의 변화 크기도 %p로 확인한다. |
| ④ 금리 스프레드 | **스프레드 = 서민금융 제외 평균금리 - 평균금리** |

## 9. 해석 시 주의사항

- 평균신용점수는 전체 차주 분포가 아닌 평균값이므로 이것만으로 신용점수 구간별 취급비중을 확인할 수 없다.
- 8% 이상 고금리 대출 취급비중은 분석기간 동안 전반적으로 낮아지는 흐름을 보였지만 모든 은행과 모든 시점에서 지속적으로 감소한 것은 아니다. 특히 토스뱅크는 2026-06에 **31.7%**를 기록했다.
- 고금리비중이 매우 낮거나 0%인 경우 상대 변화율은 실제 변화보다 크게 보일 수 있으므로 **원자료 수준 + 전월 대비 변화율 + 전월 대비 %p 변화**를 함께 확인한다.
- 본 프로젝트는 월별 집계자료를 이용한 관찰적 시계열 분석이므로, 분석 결과만으로 규제가 변화의 원인이라고 단정하지 않는다.
